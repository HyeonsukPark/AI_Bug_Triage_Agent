# AI_Bug_Triage_Agent
AI-powered bug triage assistant for GitHub Issues. This project uses GPT-4o, Pydantic, LangChain, and vector search to automate issue analysis, summarize bug reports, detect possible duplicates, suggest priorities, and assist developers during the triage process. 



## Features

- AI-generated issue summaries
- Priority suggestion
- Bug type classification
- Duplicate issue detection
- Clarifying question generation
- GitHub Issue integration via webhooks
- Lightweight dashboard for visualization
